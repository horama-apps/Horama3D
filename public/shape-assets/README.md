# Horama3D reusable shape assets

These monochrome SVG silhouettes are the shared source geometry for Pet
Keychains, Bracelet Gems, and future keychain modules.

Keep artwork as closed, filled paths. Use `fill-rule="evenodd"` when a design
contains intentional cutouts. Avoid strokes unless they are part of a closed
silhouette, and keep each asset centered inside its `viewBox`.
